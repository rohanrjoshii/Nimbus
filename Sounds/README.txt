Drop your own lock/unlock sounds here to override the defaults.

Filenames (any one extension each):
  lock.aiff   (or lock.wav / lock.m4a / lock.mp3 / lock.caf)
  unlock.aiff (or unlock.wav / ...)

Then run ./bundle.sh and reopen Arcana — they're copied into the app and
played on screen lock / unlock. Toggle the whole feature in
Settings -> Behavior -> "Lock / Unlock Sound".

Note: Apple's actual iPhone lock sound is proprietary and cannot be bundled
with the app. Supply your own file here to use it.
